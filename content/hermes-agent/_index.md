Hermes Agent is a personal automation application operated by Slava Kuznetsov.

When a user explicitly authorizes a Google account, Hermes Agent may access the Google services and data covered by that authorization to provide requested automation, including Gmail, Calendar, Drive, Contacts, Sheets, and Docs operations. Access is limited to the permissions the user grants and can be revoked in the user's Google Account settings.
